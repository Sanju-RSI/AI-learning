
# Code Review Skill

## Purpose
Review TypeScript code for quality, correctness, and maintainability.

## Instructions
1. Understand the purpose of the code.
2. Identify bugs and incorrect logic.
3. Check error handling.
4. Check TypeScript type safety.
5. Identify security and performance problems.
6. Identify duplicate or unnecessary code.

## Output Format
For every issue, provide:

- Severity: Critical / High / Medium / Low
- File and line number
- Problem description
- Why it matters
- Suggested solution

## Rules
- Do not modify source code unless explicitly requested.
- Do not report issues without explaining them.
- Prioritize real problems over stylistic preferences.
